# Kantong (versi offline)

Isi folder ini:
- index.html  : aplikasinya
- sw.js       : bikin aplikasi bisa jalan tanpa internet
- manifest.webmanifest, icon-*.png, apple-touch-icon.png : biar bisa dipasang di layar utama

Cara pasang (GitHub Pages, gratis):
1. Buat akun di github.com, lalu buat repositori baru (Public), misalnya "kantong".
2. Upload semua file di folder ini ke repositori itu (bukan zip-nya, tapi isinya).
3. Buka Settings > Pages. Di Branch pilih "main" dan folder "/ (root)", lalu Save.
4. Tunggu 1-2 menit. Alamatnya: https://NAMAKAMU.github.io/kantong/
5. Buka alamat itu di Safari (iPhone), tunggu sampai halaman muncul, lalu Bagikan > Tambah ke Layar Utama.
6. Buka sekali lewat ikon itu selagi ada internet. Setelah itu bisa dipakai offline.

Cadangan data: tekan "Ekspor CSV" di bagian Riwayat, lalu simpan filenya.
Data tersimpan di perangkat ini saja, tidak ikut ke internet dan tidak sinkron antar perangkat.
